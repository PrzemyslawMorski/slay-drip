## User story

Requirement served: none names containerised tooling. It enables F7 (through S1-06) and the local-run rule in CLAUDE.md. See the spec's Problem section.

```gherkin
Feature: ADRs match the containerised tooling
  As a considered dresser
  I want the Go test stack decision to say where tests run
  So that the ADRs and the repo agree
```

ADR-0007 says tests run in the inner loop with no Docker and that `-race` runs only in CI because of cgo. ADR-0005 says developers run a Go toolchain and Python on the host. Each gets a dated amendment that links ADR-0014, in the style of the ADR-0010 amendment. Governing design: [ADR-0014](../adr/0014-containerised-dev-tooling.md). Spec: [S1-07](S1-07-containerised-dev-tooling.md).
