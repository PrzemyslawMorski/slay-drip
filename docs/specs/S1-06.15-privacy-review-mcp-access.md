## User story

```gherkin
Feature: MCP access is checked against the privacy rules before it ships
  As a considered dresser
  I want the MCP access to be reviewed against consent, age, region and data minimisation
  So that the AI client gets no more of my data than the rules allow
```

Context: a read-only review of the whole spec. It also checks the first-class rule (F7.4): each tool in this change must pass the five-step checklist in S1-06's Design section.

## Acceptance criteria

```gherkin
Scenario: A person without wardrobe consent is refused
  Given a signed-in person who has not consented to wardrobe photos
  When the client calls "wardrobe_upload_image"
  Then the call is refused with a message that names the missing consent

Scenario: A person under 18 cannot use the endpoint
  Given an account that failed the 18+ gate
  When the client calls any MCP tool
  Then the call is refused
```
