## User story

```gherkin
Feature: Signed-in person saves an outfit through an AI client
  As a considered dresser
  I want my AI client to save an outfit made from my own items
  So that I can keep looks I like without switching to the app
```

Context: the outfit tool. It can only use the person's own item IDs. An item owned by someone else gives "not found", so one person cannot probe another's IDs.

## Acceptance criteria

```gherkin
Scenario: A person cannot act on another person's items
  Given person A owns an item and person B is signed in
  When person B calls "outfit_create" with A's item ID
  Then the call returns "not found"
  And no outfit is saved
```
