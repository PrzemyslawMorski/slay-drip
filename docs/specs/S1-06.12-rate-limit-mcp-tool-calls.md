## User story

```gherkin
Feature: MCP tool calls are rate-limited per account
  As a considered dresser
  I want my AI client's calls capped per account
  So that one script or client cannot exhaust the service or its storage
```

Context: the limiter itself is built in S1-05 for the other authenticated routes. This ticket wraps the MCP call path with it, so the same limit and the same error shape apply to tools.

## Acceptance criteria

```gherkin
Scenario: Excess calls are rate-limited
  Given a signed-in person who has reached the per-account limit
  When the client calls any tool again
  Then the call returns a rate-limit response and no work is done
```
