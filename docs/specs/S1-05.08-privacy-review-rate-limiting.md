## User story

Requirement served: security guide §10 and §6 (logging), with the blocking rules in the [security guide](../security.md).

```gherkin
Feature: Rate limiting on account and wardrobe routes
  As a considered dresser
  I want the service to refuse bursts of requests from one account
  So that one account or a script cannot exhaust the service or its storage
```

A read-only review of the limiter, the middleware and the route list before the spec closes.

## Acceptance criteria

```gherkin
Scenario: The rate limiter logs no subject identifier and stores no personal data
  Given the limiter, the middleware and the route list are merged
  When their logs and storage are inspected
  Then the logs contain the route category and the count only
  And no personal data is written to any store, and the counts exist in memory only
  And the single-instance limit is recorded in the PR
```
