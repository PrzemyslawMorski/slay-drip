## User story

Requirement served: none names containerised tooling. It enables F7 (through S1-06) and the local-run rule in CLAUDE.md. See the spec's Problem section.

```gherkin
Feature: The guide shows the containerised commands and the spec is closed
  As a considered dresser
  I want one guide whose commands all start with docker compose
  So that I can set up with only Docker and the S1-06 MCP work can start
```

Rewrites `docs/local-development.md` so its prerequisites list only Docker and every command runs through a tool service, then sets this spec to Done. Blocked on an ownership decision: `docs/local-development.md` is not an owned path of any role in `roles.md`, so the checker rejects it in a Files list (the same problem S1-03.03 recorded). The planner cannot edit `.claude/`. Governing design: [S1-07](S1-07-containerised-dev-tooling.md). Spec: [S1-07](S1-07-containerised-dev-tooling.md).
