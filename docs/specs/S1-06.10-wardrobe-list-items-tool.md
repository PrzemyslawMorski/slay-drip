## User story

```gherkin
Feature: Signed-in person lists their wardrobe through an AI client
  As a considered dresser
  I want my AI client to list my wardrobe items with their state
  So that the assistant can pick from what I own, and sees no more of my data than it needs
```

Context: the second tool. Its output must carry only the fields the tool lists, which is the data-minimisation rule (security guide §8).

## Acceptance criteria

```gherkin
Scenario: Tool output does not carry more personal data than the tool needs
  Given a person with items that have names and notes
  When the client calls "wardrobe_list_items"
  Then the response contains only the fields listed for that tool
```
