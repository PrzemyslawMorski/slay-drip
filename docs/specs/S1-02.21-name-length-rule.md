## User story

```gherkin
Feature: Outfit names are limited to 60 characters
  As a considered dresser
  I want to build and save outfits from my own items
  So that I can record the looks I already like
```

Context: [S1-02](S1-02-manual-outfit-creation.md) (manual outfits from wardrobe photos, device-only). Scope is frontend-only unless the brief says otherwise.

## Acceptance criteria

```gherkin
Scenario: An outfit name longer than 60 characters is rejected
  Given I am creating an outfit with 1 wardrobe item
  When I enter a name of 61 characters and choose "Save outfit"
  Then I see an error that the name must be 60 characters or fewer
  And no outfit is saved
```
