## User story

Requirement served: F1.1 (18+ gate at sign-up), BE-49.

```gherkin
Feature: API gate on the 18+ self-declaration
  As a considered dresser
  I want the API to refuse user routes until I declare that I am 18 or over
  So that no under-18 person keeps an account or has data stored
```

Context and design are in [S1-04](S1-04-server-side-18plus-gate.md). Only a self-declared boolean is stored, as the Keycloak user attribute `over18_declared`. No age, date of birth or birth year is stored or logged.

## Acceptance criteria

```gherkin
Scenario: A user route is refused until the declaration is recorded
  Given a newly registered user holds a verified access token
  And no "over18_declared" attribute is set for that subject
  When the user calls GET /wardrobe/items
  Then the API answers 403 with error "age_declaration_required"

Scenario: An adult declaration sets the attribute once
  Given a newly registered user holds a verified access token
  When the user sends POST /me/age-declaration with "over18": true
  Then the API sets "over18_declared" to "true" for that subject through the Keycloak admin client
  And the API answers 204

Scenario: An under-18 declaration deletes the account
  Given a newly registered user holds a verified access token
  When the user sends POST /me/age-declaration with "over18": false
  Then the API deletes the Keycloak user for that subject through the admin client
  And the API answers 403 with error "age_declaration_failed"
  And no wardrobe, consent or outfit row exists for that subject

Scenario: A failed account delete is not reported as success
  Given the Keycloak admin client cannot delete the user
  When the user sends POST /me/age-declaration with "over18": false
  Then the API answers 503 with error "age_declaration_retry"
  And the declared value is not logged

Scenario: A declaration in a later request body is ignored
  Given a user has a verified token and no "over18_declared" attribute
  When the user sends GET /wardrobe/items with a body field "over18" set to true
  Then the API answers 403 with error "age_declaration_required"
```
