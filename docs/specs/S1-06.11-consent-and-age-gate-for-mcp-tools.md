## User story

```gherkin
Feature: MCP tools honour consent and the 18+ gate
  As a considered dresser
  I want every AI client call to check my consent and age first
  So that no wardrobe photo is used without my consent and no under-18 account is served
```

Context: a hard rule (TDD-05). The gate sits on the MCP call path, before any tool runs, so every tool gets it without copying the check. It reuses the server-side 18+ check from S1-04 and does not add a second one.

## Acceptance criteria

```gherkin
Scenario: A person without wardrobe consent is refused
  Given a signed-in person who has not consented to wardrobe photos
  When the client calls "wardrobe_upload_image"
  Then the call is refused with a message that names the missing consent

Scenario: A person under 18 cannot use the endpoint
  Given an account that failed the 18+ gate
  When the client calls any MCP tool
  Then the call is refused
```
