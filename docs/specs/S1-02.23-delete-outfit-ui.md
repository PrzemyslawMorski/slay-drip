## User story

```gherkin
Feature: Deleting an outfit asks for confirmation and keeps its items
  As a considered dresser
  I want to build and save outfits from my own items
  So that I can record the looks I already like
```

Context: [S1-02](S1-02-manual-outfit-creation.md) (manual outfits from wardrobe photos, device-only). Scope is frontend-only unless the brief says otherwise.

## Acceptance criteria

```gherkin
Scenario: Deleting an outfit keeps its items in my wardrobe
  Given I have saved an outfit named "Weekend" with 2 items
  And my wardrobe shows 3 items
  When I delete "Weekend" and confirm the deletion
  Then "Weekend" is no longer in my outfits
  And my wardrobe still shows 3 items
```
