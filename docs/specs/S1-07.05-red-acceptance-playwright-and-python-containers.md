## User story

Requirement served: none names containerised tooling. It enables F7 (through S1-06) and the local-run rule in CLAUDE.md. See the spec's Problem section.

```gherkin
Feature: Playwright and Python tool containers, acceptance tests
  As a considered dresser
  I want executable checks that the browser tests and the smoke scripts are defined as container runs
  So that the Playwright run and the Python image start from failing scenarios
```

Static checks on the Playwright run definition and the `python` tool service. The live runs are the Done-when checks of S1-07.08 and S1-07.09. Governing design: [S1-07](S1-07-containerised-dev-tooling.md). Spec: [S1-07](S1-07-containerised-dev-tooling.md).

## Acceptance criteria

```gherkin
Scenario: Playwright acceptance tests run in the Playwright container
  Given the Node tool service with the Playwright browsers
  When a developer runs "npm run test:acceptance" through it
  Then the acceptance scenarios run in the container against the stack
  And the result is reported as it is on a host install

Scenario: Python scripts run in the Python container
  Given the Python tool service and the local stack running
  When a developer runs the S3 and Keycloak smoke scripts through it
  Then each script runs in the container using only the standard library
  And a passing run ends with its usual OK line
```
