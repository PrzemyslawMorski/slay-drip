## User story

```gherkin
Feature: Elicitation behaviour is known before the tools rely on it
  As a considered dresser
  I want the server to be honest with clients that cannot take a question
  So that an older AI client gets a clear answer and never a silent failure
```

Context: the ADR-0012 amendment says the stateless handler cannot deliver server-initiated requests to clients below 2026-07-28, and that the SDK's legacy path in stateless mode is not verified. This Spike writes a discovery note that says what the SDK docs establish and what a test must run.

## Acceptance criteria

```gherkin
Scenario: A client without elicitation gets an honest request for more information
  Given a signed-in person with wardrobe consent, and a client that does not support elicitation
  When the client calls "wardrobe_upload_image" without a category
  Then the call returns a result that says a category is needed
  And no item is stored
```
