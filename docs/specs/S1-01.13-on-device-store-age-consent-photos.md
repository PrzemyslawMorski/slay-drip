## User story

Requirement served: F2.2 single-item capture and the wardrobe view that follows it, with no account (spec [S1-01](S1-01-anonymous-wardrobe-upload.md)).

```gherkin
Feature: On-device store for age confirmation, consent and photos
  As a considered dresser
  I want the anonymous wardrobe behaviour in S1-01
  So that this ticket's scenarios can be checked against the spec
```

Frontend only. Photos stay on the device under [ADR-0004](../adr/0004-on-device-wardrobe-storage.md).

## Acceptance criteria

```gherkin
Scenario: The wardrobe still shows its items after the app is reloaded
  Given I have confirmed that I am 18 or over
  And I have agreed to store photos of my clothes on this device
  And I have added 3 photos to my wardrobe
  When I reload the app
  Then I see 3 photos of clothing items in a grid
```

## Notes

**Agent brief**

- **Role:** `data-engineer` (see `.claude/skills/tickets-from-spec/references/roles.md`)
- **Goal:** Persist the age confirmation, the consent flag and the photos in IndexedDB so they survive a reload.
- **Read first:** [ADR-0004](../../docs/adr/0004-on-device-wardrobe-storage.md), [frontend ruleset section 6](../../docs/code-review/frontend-ruleset.md)
- **Files to change:**
  - `frontend/src/storage/localDb.ts`, what changes in it
  - `frontend/src/storage/localDb.test.ts`, what changes in it
- **Do not touch:** anything outside the role's owned paths, and the files the neighbouring tickets change.
- **Covers scenarios:** `The wardrobe still shows its items after the app is reloaded`
- **Done when:** `npm run test:unit` and `npm run typecheck` in `frontend/`, then `npm run test:acceptance` for the reload scenario.
- **Out of scope:** Deletion on withdrawal is S1-01.16; the read-error signal is S1-01.23.
- **Open questions:** Which role owns `frontend/src/wardrobe/` (the wardrobe store that calls this module) is not set in roles.md. Owner to assign before this ticket is dispatched.

Writes go through the storage module only. Reads report failure rather than returning an empty list (used by S1-01.23). Covers the reload scenario. Wiring into `frontend/src/wardrobe/` is outside any role's owned paths.
