## User story

Requirement served: none names local stack tooling (gap, see the spec). It enables the local-run rule in CLAUDE.md.

```gherkin
Feature: can the full stack start in 10 seconds and what does each step cost
  As a considered dresser
  I want the whole app to run locally in its own worktree
  So that I and the agents can test it end to end without clashes
```

One discovery note with per-service start timings (PostgreSQL, SeaweedFS, Keycloak start-dev with realm import, API) from a cold project with images pulled, and a recommendation that confirms the 10 s budget or says how to reach it (for example a pre-built Keycloak image, a lighter realm import, parallel start). Governing design: [S1-08](S1-08-local-stack.md), [ADR-0016](../adr/0016-per-worktree-local-stack.md).

## Acceptance criteria

```gherkin
Scenario: The start budget is measured per step
  Given a cold project with the images already pulled
  When each service is started and timed
  Then the note lists the time to healthy for every service
  And it states whether 10 seconds is reachable
```
