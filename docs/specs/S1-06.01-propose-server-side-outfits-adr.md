## User story

```gherkin
Feature: Server-side outfits for signed-in people
  As a considered dresser
  I want my saved outfits to be available to my AI client when I am signed in
  So that the outfit tools in S1-06 have a store to write to, without changing how anonymous outfits are kept
```

Context: S1-02 and ADR-0004 keep outfits in the browser only. S1-06 needs server-side outfits for signed-in people, which is a new store with personal data. This Spike writes one proposed ADR. It does not choose the store for anyone.

## Acceptance criteria

```gherkin
Scenario: A person cannot act on another person's items
  Given person A owns an item and person B is signed in
  When person B calls "outfit_create" with A's item ID
  Then the call returns "not found"
  And no outfit is saved
```
