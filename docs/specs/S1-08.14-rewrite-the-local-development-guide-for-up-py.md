## User story

Requirement served: none names local stack tooling (gap, see the spec). It enables the local-run rule in CLAUDE.md.

```gherkin
Feature: Rewrite the local development guide for up.py
  As a considered dresser
  I want the whole app to run locally in its own worktree
  So that I and the agents can test it end to end without clashes
```

docs/local-development.md leads with `python scripts/dev/up.py up`, and covers the stack file, the test database, worktree ports, the Vite proxy and the Playwright command, and the config contract local values. Governing design: [S1-08](S1-08-local-stack.md), [ADR-0016](../adr/0016-per-worktree-local-stack.md).

## Acceptance criteria

```gherkin
Scenario: No .env file is read
  Given a new worktree with no .env file
  When I run "python scripts/dev/up.py up"
  Then the stack starts and no .env file is read or created
  And every local value comes from compose.yaml or a committed file under infra/dev/
```
